Modernized client UI for macOS, Linux and Android.

- A clearer default-profile card, connection status and primary action.
- Native desktop navigation with network settings moved into Settings.
- WebView Profiles / Settings / Sync navigation and mode-specific settings.
- Android grouped import/settings actions, English/Russian labels, and the status-colored bottom connection button.
- Shared encrypted profile storage and automatic TrustTunnel / Hysteria 2 selection.

Packages:
- macOS Apple Silicon: UI Choices DMG contains Native, WebView and Both PKG installers. No Developer ID/notarization; macOS may require individual approval.
- Linux x86_64 Wayland: Native, WebView and Both Flatpak bundles signed with the existing project key. The Arch host-service package is provided separately.
- Android arm64/x86_64: signed in-place update, versionCode 30208 (versionName remains 0.3.2-preview.6).
- Windows is deferred while its build node is unavailable; no older Windows installer is included as a new build.

This remains a preview release. Verify downloads using SHA256SUMS and its detached signature; the signing public key is included.

The installed macOS app/service and Linux Native/host service were checked after upgrade. WebView and Both packages passed smoke on physical KDE Wayland. Android build 30208 was installed and verified on Huawei with Always-on/lockdown retained. See release-evidence.json for build provenance and scope.
