# v0.3.2-ui.2 — Flow branding preview

The selected client icon, **#6 Flow / Поток**, is now included in Native and
WebView windows and tray, macOS app bundles, Linux Flatpak and Android launcher
and notifications. Android adaptive artwork stays within its safe zone; Android
13 includes themed monochrome artwork. The Windows native executable, installer
and shortcuts are configured to use the same ICO; no new Windows binary is
published while its build node is unavailable.

Packages:

- macOS arm64: UI Choices DMG (Native / WebView / Both), plus the Native system PKG. Ad-hoc sealed; no Developer ID/notarization.
- Linux x86_64 Wayland: three signed Flatpak variants and the signed Arch host service package `rtrust-host-0.3.2-23`.
- Android arm64/x86_64: signed APK, versionCode **30209**, versionName **0.3.2-preview.7**. Retains the existing signing certificate.

Validation: macOS Jenkins **#73**, Linux **#23** and Android **#30** completed
SUCCESS, including Gitleaks/Trivy, unit, smoke and applicable network E2E.
Android covered both transports and reinstall/upgrade. Every macOS package was
expanded: icon hashes and sealed app bundles were checked. All three Flatpak
payloads contain the canonical SVG; APK adaptive, monochrome and notification
resources were checked. This wave packages branding; installation on physical
phones/desktops was not repeated. Earlier installed UI acceptance is documented
in [v0.3.2-ui.1](v0.3.2-ui.1.md).

Two CI fixture timing races were resolved without relaxing assertions: Linux
autostart arguments are written atomically, and the pinned Hysteria binary is
prepared before timing Android fixture readiness. Failed builds remain recorded.
The release evidence records source manifests and the scope of validation.

fingerprint is `CB9C4FB4B9CFAF255BE008C9F0E6162B056843CC`.
