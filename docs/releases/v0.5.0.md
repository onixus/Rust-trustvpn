# v0.5.0 — mobile widgets and managed routes preview

- iPhone preview with profile import/export, QR import, portal synchronization,
  On Demand and a small VPN widget. Device installation requires Apple signing.
- Android VPN widget and updated shared mobile policy handling.
- macOS glass appearance with a persistent Settings toggle and accessibility fallback.
- Desktop IPv4 TUN inclusion/exclusion rules, LAN bypass and server-assigned route
  groups. The portal publishes group revisions per registered device; the desktop
  client applies them after synchronization while disconnected and reconnecting.
- HTTP requests on the desktop mixed proxy port.
- Additive server image upgrades and Linux server API/publication tests.

Route groups are desktop-only; Android/iOS do not consume the separate group API.
Existing mobile profile-embedded routing policies remain supported. This is a
preview release. macOS packages are ad-hoc sealed, not Developer-ID notarized;
Windows packages are not Authenticode signed. Validation and artifact provenance
are recorded in the release's evidence file and final publication notes.
