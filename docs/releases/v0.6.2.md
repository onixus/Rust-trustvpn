# v0.6.2-beta.1 — macOS guard proof, macOS lifecycle, Android sleep recovery

Beta pre-release. Workspace version 0.6.2, desktop update **sequence 12**, Android
versionName `0.6.2-beta.1` / versionCode 60201, iOS 0.6.2 (60201). Built from the
`v0.6.2-beta.1` tag. Only **macOS** and **Android** packages are published; the
Windows installer and Linux packages stay at [v0.6.1](v0.6.1.md) and [v0.6.0](v0.6.0.md).
The desktop update channel is not promoted.

Previous release: [v0.6.1](v0.6.1.md) (Android `0.6.1-preview.1` / 60101).

## What changed since v0.6.1

### macOS
- **Guard (kill switch) proof by a BPF tap** (#96, issue #81). PF drops output
  silently: `sendto` succeeds while nothing leaves, so no errno can prove the guard.
  The service sends one byte to each physical interface's own gateway (port 9),
  watches the interface on a read-only BPF tap, and needs a control frame of its own
  output in the same window (a query into the tunnel). On the wire is `failed`;
  silence with a seen control and our block rule counting is `passed`; anything else
  is `unknown`. See [VPN observations](../vpn-observations.md).
- **Desktop service probes** (#84, #91): DNS and guard rows come from the service in
  whole-computer mode; selected-networks mode reports them as unsupported.
- **Stop and reconnect** (#80, #94): Stop runs on its own supervisor, Status answers
  meanwhile, one route-table snapshot per batch; `stop_timing` and `reconnect_timing`
  durations (no addresses) are written to `events.log`.
- **Foreign PF states** (#95): states left by another VPN (Cisco AnyConnect) are
  flushed after our guard is loaded instead of refusing to connect.

### Android
- **Sleep recovery** (#92): the reconnect budget is restored after a stable session,
  backoff and session age use real time across sleep, wake-up checks the transport.
- **Network changes** (#86, #89): an IPv6 address or route appearing after Wi-Fi
  returns no longer rebuilds the session.
- **UI variant 3** (#73) with route/DNS/HTTPS checks through the VPN network.

### All clients
- Dead-session detection (#69), UI variant 3 on Native/WebView/iOS (#74), Linux
  terminal client (#72), lab acceptance for failover and route explain (#87, #88).

## Updating
- **macOS:** quit R-TrustTunnel first; the package's `preinstall` refuses while the
  app runs (the installer shows only a generic script error).
- **Android:** 0.6.0 and 0.6.1 update in place, profiles are kept. 0.5.x and older
  must be uninstalled first (different signing key), which deletes local profiles.
