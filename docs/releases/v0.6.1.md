## What changed since v0.6.0

### All clients (Android, Windows, macOS, Linux, iOS)

- The connection status shows only checks that produced a result. Route,
  DNS, guard and connectivity have no runtime producer yet, so they are no longer
  listed as "unchecked". A running transport reads "Transport: running". The amber
  colour still means that nothing is verified, and failed, stale or unsupported
  results are shown (#67).

### Android

- Release APKs are signed with the 0.6.0 release key (certificate SHA-256
  `4aa431cd…77306af`). `scripts/sign-android.py` reads it from the Gradle
  `keystore.properties` file and refuses any other certificate (#66). Installations of
  0.6.0 update in place. Installations of 0.5.x and earlier, which were signed with
  the retired key, must be reinstalled, which removes their local profiles.
- Field report: on `0.6.0-preview.1` the T-Bank app detected the tunnel. On
  `0.6.0-preview.2` and later it works through the VPN (Honor DEL-LX9, Android 12,
  production profile, Always-on and lockdown off, 2026-10-13).
