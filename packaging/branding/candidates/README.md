candidates. Option 6 (Flow / Поток) was selected for the client.
Canonical platform assets live in the parent directory.

Open `index.html` to compare full-size and small-size previews.

After selection, derive Windows ICO, macOS ICNS, Linux SVG/PNG, Android adaptive
foreground/background and tray variants from the selected vector. Package and
validate them through the existing release workflows. Keep platform assets and
small monochrome tray variants visually consistent with the chosen mark.
